# Express Server

A simple Express.js server to demonstrate backend server setup and routing.

## Features

- Basic Express server setup
- Configurable port
- Sample route demonstrating server response
- Easy to extend for building APIs or web apps

## Technologies Used

- Node.js
- Express.js

## Getting Started

### Prerequisites

- Node.js and npm installed

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/siddhraj1412/FSWD-Mini-Projects.git
cd FSWD-Mini-Projects/7-express-server
```

Install dependencies:

```bash
npm install
```

### Running the Server

Start the server:

```bash
npm start
```

By default, the server runs on port 3000. You can access the server at:

```
http://localhost:3000/
```
