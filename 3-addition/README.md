# Addition App

A simple addition app built with JavaScript, run using Node.js and npm.

## Features

- Inputs to enter two numbers
- Calculates and displays the sum
- Clear/reset inputs functionality

## Technologies Used

- JavaScript
- Node.js/npm for running the app
- HTML and CSS for UI

## Getting Started

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/siddhraj1412/FSWD-Mini-Projects.git
cd FSWD-Mini-Projects/3-addition
```

Install dependencies (if any):

```bash
npm install
```

### Running the App

Start the application with:

```bash
npm start
```

This will run the addition app, typically opening it in the browser or launching a local server depending on your setup.

## Project Structure

```
├── package.json
├── index.html
├── style.css
├── script.js
└── README.md
```

- `index.html` is the main HTML file  
- `style.css` contains styling  
- `script.js` holds addition logic  
- `package.json` defines scripts and dependencies  

## Usage

- Enter numbers in the input fields  
- Click "Add" to get the sum  
- Use "Clear" to reset fields
