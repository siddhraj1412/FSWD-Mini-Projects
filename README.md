# FSWD-Mini-Projects

A curated collection of full-stack web development mini projects focusing on JavaScript technologies including Node.js, Express, React, MongoDB, and frontend development with HTML, CSS, and EJS.

## About

This repository hosts a variety of practical mini projects aimed at learning and demonstrating foundational and intermediate web development skills. It covers both frontend and backend aspects, illustrating how to build interactive, responsive, and data-driven applications using popular frameworks and tools.

## Technologies Used

- JavaScript (ES6+)
- Node.js and Express.js
- React.js
- MongoDB and Mongoose
- HTML5 and CSS3
- EJS templating engine
- Local Storage for client-side data management

## Projects Overview

The repository features diverse projects, including but not limited to:

- React Navigation Demo Apps
- CRUD APIs with Express and MongoDB
- User Authentication and Signup Forms
- Interactive Product Cards
- Simple Utility Apps like Counters and Calculators
- To-Do List Applications with full stack implementations

Each project stands as a self-contained application or demo that can be cloned, run, and customized independently.

## Getting Started

To use any project:

1. Clone this repository:
   ```bash
   git clone https://github.com/siddhraj1412/FSWD-Mini-Projects.git
   ```

2. Navigate to the desired project directory:
   ```bash
   cd FSWD-Mini-Projects/<project-folder>
   ```

3. Follow individual project README or instructions for installation and running.
